# RFC-001 — Decisão de Uso do Banco de Dados H2

**Projeto:** SOS Rota — Eng5 2026/1  
**Responsável:** Gabriella Pio (GCS)  
**Data de registro:** 03/06/2026  
**Versão aplicada:** v0.1.0  
**Status:** ✅ Aprovada — implementada #4

---

## 1. Descrição

Esta RFC registra formalmente a decisão arquitetural de utilizar o banco de dados **H2 em memória** como solução de persistência do sistema SOS Rota no semestre Eng5 2026/1.

---

## 2. Justificativa

| Motivo                                  | Descrição                                                                                                                                                |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Simplicidade de ambiente**            | O H2 é embarcado na aplicação Spring Boot, eliminando a necessidade de instalação e configuração de um serviço de banco externo em cada máquina do grupo |
| **Facilidade no CI**                    | O pipeline de integração contínua (GitHub Actions) não precisa provisionar um serviço de banco de dados externo para executar o build e os testes        |
| **Escopo acadêmico**                    | O projeto tem prazo de 2 semanas e foco em demonstração funcional — a persistência em memória é suficiente para o escopo exigido pelo PI                 |
| **Redução de complexidade operacional** | Sem dependência de credenciais, conexões externas ou variáveis de ambiente de banco para rodar localmente                                                |
| **Suporte nativo do Spring Boot**       | O Spring Boot oferece suporte out-of-the-box ao H2, com console web acessível em `/h2-console` para inspeção dos dados                                   |

---

## 3. Impacto

### Backend

- `pom.xml`: dependência `com.h2database:h2` adicionada no escopo `runtime`
- `application.properties`: configuração do datasource apontando para H2 em memória
- Flyway **não será utilizado** — o schema será gerado automaticamente pelo Hibernate (`spring.jpa.hibernate.ddl-auto=create-drop`)
- Console H2 habilitado para ambiente de desenvolvimento (`spring.h2.console.enabled=true`)

### Frontend

Nenhum impacto. O frontend consome a API REST independentemente do banco utilizado.

### Banco de Dados

- Dados **não são persistidos** entre reinicializações da aplicação
- Para popular dados iniciais, será utilizado o arquivo `data.sql` em `/backend/src/main/resources/` (se necessário)
