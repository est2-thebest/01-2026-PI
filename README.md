# 01-2026-PI - SOS Rota - Sistema de Gestão de Ocorrências e Despacho

O **SOS Rota** é uma solução para gerenciamento de ocorrências, recursos, acompanhamento de atendimentos e geração de informações úteis à tomada de decisão. O projeto integra os requisitos multidisciplinares do 5º período de Engenharia de Software.

## Tecnologias

- **Backend:** Java 21 + Spring Boot
- **Frontend:** Angular 17+ (Node 20+)
- **Infraestrutura:** Pipeline CI/CD (GitHub Actions) + Modelagem AWS.

---

## Como Executar

### Backend

```

cd backend && mvn spring-boot:run

```

Acesse: http://localhost:8080

### Frontend

```

cd frontend && npm install && ng serve

```

Acesse: http://localhost:4200

```
